Arduino UNO Code using Platform IO extension for running CoreXY Gantry (Nema 17) and g-code parsing. 

For my Diamond Painting Robot; works in tandem with Diamond_Painting_Repo. 

 This robot is a core-xy gantry that places colored resin "diamonds" on a sticky, color-coded chart to form a picture.

The code is split into two repos: Python and C++. The Arduino parses the Python commands into stepper-motor movements and controls the pen pick-and-place.
